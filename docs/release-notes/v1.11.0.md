Le mode Songes lit tous les groupes affichés, sur toutes les cartes, et Dofight fonctionne sur macOS. / Dreams mode reads every group on screen, on every map, and Dofight runs on macOS.

## Français

**Nouveautés**
- Le mode Songes lit tous les groupes affichés dans la fenêtre, plus seulement celui sous la souris : affiche-les tous avec la touche du jeu et ils arrivent dans la seconde.
- Dofight fonctionne sur macOS.

**Améliorations**
- Le mode Songes explique ce que Dofight capture et ce qu'il en garde ; le guide, l'explication de « Lecture de l'écran » et le README disent la même chose.
- Le « i » des options reste collé au nom quand celui-ci passe sur plusieurs lignes.
- « Songes » s'écrit toujours au pluriel dans toute l'interface.

**Corrections**
- Le mode Songes reconnaît les groupes sur les cartes sombres, lit les groupes en entier jusqu'à huit monstres, reconnaît mieux les noms mal lus, et lit trois fois plus vite.
- Le mode Songes ne relit plus les mêmes infobulles quand les groupes se déplacent, et oublie ceux de la carte d'avant quand tu changes de carte.
- Les combats sont de nouveau reconnus quand la fenêtre du jeu n'est pas à sa taille de référence : le panneau s'ouvre en combat et se referme après.
- Le journal de diagnostic et les suggestions ne contiennent plus de texte lu à l'écran : seulement ce que Dofight en a compris.
- Le journal dit quand le mode Songes attend la fin d'un combat, au lieu de ne rien lire sans rien dire.

## English

**New**
- Dreams mode reads every group shown in the window, not only the one under the mouse: show them all with the game's own key and they arrive within a second.
- Dofight runs on macOS.

**Improvements**
- Dreams mode explains what Dofight captures and what it keeps; the guide, the "Screen reading" explanation and the README say the same.
- An option's "i" stays next to its name when the name wraps onto several lines.
- "Dreams" is always written in the plural throughout the interface.

**Fixes**
- Dreams mode recognises groups on dark maps, reads whole groups of up to eight monsters, is better at names the reading got wrong, and reads three times faster.
- Dreams mode no longer re-reads the same tooltips when the groups move about, and forgets the previous map's groups when you change map.
- Fights are recognised again when the game window is not at its reference size: the panel opens in a fight and closes after it.
- The diagnostic log and suggestions no longer hold text read from the screen: only what Dofight made of it.
- The log says when Dreams mode is waiting for a fight to end, instead of reading nothing and saying nothing.
